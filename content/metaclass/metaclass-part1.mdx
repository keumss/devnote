Python 메타클래스는 프레임워크나 플러그인 시스템처럼 여러 클래스가 같은 선언 규칙을 따라야 할 때 클래스 생성 자체를 검사하고 확장합니다. 먼저 클래스도 객체라는 모델을 확인하고, `type`과 `metaclass=`로 생성 규칙을 연결한 뒤 더 단순한 훅을 선택할 수 있는 기준까지 익힙니다.

## type()으로 클래스와 인스턴스의 관계 확인하기

메타클래스를 이해하려면 인스턴스를 만드는 클래스와 클래스를 만드는 메타클래스를 구분해야 합니다. 일반 클래스의 인스턴스에 `type()`을 호출하면 그 클래스가 나오고, 클래스 자체에 호출하면 기본 메타클래스인 `type`이 나옵니다.

```python
class Invoice:
    pass


invoice = Invoice()

print(type(invoice).__name__)
print(type(Invoice).__name__)
print(isinstance(Invoice, type))
```

```text
Invoice
type
True
```

`Invoice()`는 `Invoice`가 인스턴스를 만드는 호출이고, `class Invoice:` 문은 기본적으로 `type`이 `Invoice` 클래스 객체를 만드는 과정입니다. 메타클래스는 이 두 번째 생성 과정을 바꿉니다.

## metaclass=로 클래스 생성 규칙 연결하기

클래스가 만들어지는 순간 공통 처리를 실행하려면 `type`을 상속한 메타클래스를 정의하고 `metaclass=`로 연결합니다. `__new__()`는 클래스 이름, 기반 클래스 튜플, 클래스 본문이 채운 네임스페이스를 받습니다.

```python
class TraceMeta(type):
    def __new__(mcls, name, bases, namespace):
        print(f'클래스 생성: {name}')
        return super().__new__(mcls, name, bases, namespace)


class Task(metaclass=TraceMeta):
    pass


print(type(Task).__name__)
```

```text
클래스 생성: Task
TraceMeta
```

첫 번째 매개변수 `mcls`는 메타클래스 자신입니다. `super().__new__()`가 실제 클래스 객체를 만들도록 반드시 호출하고, 생성 전후에 필요한 검사나 변환을 둡니다.

## type(name, bases, namespace)로 클래스 동적 생성하기

클래스 이름과 속성을 실행 중에 조합해야 할 때 `type()`의 세 인수 형식으로 클래스 객체를 직접 만들 수 있습니다. 다음 코드는 메서드와 클래스 속성을 가진 `Product`를 생성합니다.

```python
def label(self) -> str:
    return f'{self.category}:{self.name}'


Product = type(
    'Product',
    (),
    {'category': 'office', 'label': label},
)

product = Product()
product.name = 'keyboard'
print(product.label())
```

```text
office:keyboard
```

세 인수는 각각 클래스 이름, 기반 클래스 튜플, 속성 네임스페이스입니다. 고정된 클래스는 보통 `class` 문이 더 읽기 쉽고, 스키마나 설정에서 여러 클래스를 생성할 때만 동적 생성을 선택합니다.

## __new__()로 클래스 선언 규칙 검사하기

모든 하위 모델이 자체 `table` 속성을 선언해야 한다면 클래스 생성 시점에 빠진 선언을 거부할 수 있습니다. 잘못된 클래스는 인스턴스를 만들기 전, 모듈을 불러오는 시점에 바로 실패합니다.

```python
class TableMeta(type):
    def __new__(mcls, name, bases, namespace):
        if bases and 'table' not in namespace:
            raise TypeError(f'{name}에 table 선언이 필요합니다.')
        return super().__new__(mcls, name, bases, namespace)


class Model(metaclass=TableMeta):
    pass


class User(Model):
    table = 'users'


print(User.table)
```

```text
users
```

`'table' in namespace`는 상속된 값이 아니라 해당 클래스 본문에 직접 쓴 값만 확인합니다. 상속을 허용하려면 클래스 생성 후 `hasattr(cls, 'table')`로 검사하는 편이 맞습니다.

## __new__()로 공통 클래스 속성 추가하기

선언에서 반복되는 파생 값을 자동으로 만들 때 클래스 네임스페이스를 수정할 수 있습니다. 다음 메타클래스는 별도 선언이 없으면 클래스 이름에서 소문자 식별자를 만듭니다.

```python
class NamedMeta(type):
    def __new__(mcls, name, bases, namespace):
        namespace.setdefault('kind', name.lower())
        return super().__new__(mcls, name, bases, namespace)


class Payment(metaclass=NamedMeta):
    pass


class CardPayment(Payment):
    kind = 'card'


print(Payment.kind)
print(CardPayment.kind)
```

```text
payment
card
```

명시적으로 선언한 `kind`는 `setdefault()`가 덮어쓰지 않습니다. 자동 변환은 예측 가능한 규칙으로 제한하고, 중요한 업무 값은 클래스 본문에서 명시하는 편이 안전합니다.

## 메타클래스 상속으로 하위 클래스까지 등록하기

기반 클래스에 메타클래스를 한 번 연결하면 하위 클래스도 같은 메타클래스로 생성됩니다. 이 성질을 이용하면 플러그인이나 처리기 클래스를 선언할 때 자동으로 목록에 모을 수 있습니다.

```python
class RegistryMeta(type):
    names: list[str] = []

    def __new__(mcls, name, bases, namespace):
        cls = super().__new__(mcls, name, bases, namespace)
        if bases:
            mcls.names.append(name)
        return cls


class Handler(metaclass=RegistryMeta):
    pass


class EmailHandler(Handler):
    pass


class SmsHandler(Handler):
    pass


print(RegistryMeta.names)
```

```text
['EmailHandler', 'SmsHandler']
```

등록은 클래스 정의가 실행되는 즉시 일어납니다. 따라서 등록할 모듈을 아직 가져오지 않았다면 목록에도 나타나지 않는다는 점을 기억해야 합니다.

## __init_subclass__()와 클래스 데코레이터를 먼저 검토하기

하나의 기반 클래스가 하위 클래스를 확인하거나 등록하기만 한다면 메타클래스보다 `__init_subclass__()`가 간단합니다. 다음 코드는 플러그인 키를 검사하면서 하위 클래스를 사전에 등록합니다.

```python
class Plugin:
    plugins: dict[str, type['Plugin']] = {}

    def __init_subclass__(cls, *, key: str, **kwargs):
        super().__init_subclass__(**kwargs)
        if key in cls.plugins:
            raise ValueError(f'중복 플러그인: {key}')
        cls.plugins[key] = cls


class CsvPlugin(Plugin, key='csv'):
    pass


print(Plugin.plugins['csv'].__name__)
```

```text
CsvPlugin
```

한 클래스만 변환할 때는 클래스 데코레이터, 하위 클래스 생성에 반응할 때는 `__init_subclass__()`, 클래스 본문 실행 전 네임스페이스를 바꾸거나 여러 기반 클래스에 걸친 생성 정책이 필요할 때는 메타클래스를 선택합니다.
