## re 모듈로 문자열 패턴 검사 및 데이터 추출하기

이메일, 전화번호, 회원 가입 입력값 검증이나 로그 파일 해석 시 단순 문자열 메서드(`find()`, `startswith()`)만으로는 복잡한 조건 처리가 어렵습니다. 파이썬 표준 라이브러리의 `re` 모듈은 정규표현식(Regular Expression) 엔진을 제공하여 패턴 매칭, 검증, 치환, 캡처 작업을 효율적으로 수행합니다.

```python
import re

text = "문의 전화: 010-1234-5678"
pattern = r"\d{3}-\d{4}-\d{4}"

if re.search(pattern, text):
    print("유효한 전화번호 패턴 발견")
```

```text
유효한 전화번호 패턴 발견
```

- 파이썬 기본 제공 표준 모듈이므로 별도 설치 없이 `import re`로 바로 사용합니다.
- 정규표현식 패턴 문자열 선언 시 역슬래시(`\`) 탈출 문자를 그대로 전달하기 위해 원시 문자열 리터럴(`r"..."`)을 사용해야 합니다.

## re.search()로 문자열 내 첫 번째 일치 위치 탐색하기

문자열 전체를 검색하여 패턴과 일치하는 첫 번째 위치를 찾고자 할 때 사용합니다.

```python
import re

log_line = "2026-07-25 [ERROR] Connection timed out on port 8080"
match = re.search(r"\[(ERROR|WARNING)\]", log_line)

if match:
    print("매칭 문자열:", match.group())
    print("매칭 위치:", match.span())
```

```text
매칭 문자열: [ERROR]
매칭 위치: (11, 18)
```

- `re.search()`는 일치하는 항목이 있으면 `Match` 객체를 반환하고, 일치하지 않으면 `None`을 반환합니다.
- `match.group()`은 일치한 전체 문자열을 조회하고, `match.span()`은 `(시작_인덱스, 끝_인덱스)` 튜플을 반환합니다.

## re.match()로 문자열 시작 부분 일치 확인하기

문자열의 첫 글자부터 패턴과 정확히 일치하는지 확인할 때 사용합니다.

```python
import re

code = "REQ-2026-001"
match = re.match(r"REQ-\d{4}", code)

if match:
    print("요청 코드 접두사 확인:", match.group())
else:
    print("패턴 불일치")
```

```text
요청 코드 접두사 확인: REQ-2026
```

- `re.match()`는 문자열 시작점이 패턴과 일치할 때만 `Match` 객체를 반환합니다.
- 문자열 중간에 있는 패턴은 `re.match()`로 찾을 수 없으므로, 전체 탐색 시에는 `re.search()`를 선택해야 합니다.

## re.findall()로 모든 일치 항목 리스트로 추출하기

문자열 내부에서 패턴과 매칭되는 모든 항목을 문자열 리스트로 한 번에 수집할 때 사용합니다.

```python
import re

doc = "온도 측정값: 23.5C, 24.1C, 22.8C, 25.0C"
temperatures = re.findall(r"\d+\.\d+", doc)

print("추출된 온도 목록:", temperatures)
```

```text
추출된 온도 목록: ['23.5', '24.1', '22.8', '25.0']
```

- 일치하는 결과가 없으면 빈 리스트(`[]`)를 반환합니다.
- 패턴 내부에 캡처 그룹(`()`)이 포함되어 있다면 문자열 대신 그룹 매칭 결과 튜플의 리스트가 반환되므로 주의해야 합니다.

## re.finditer()로 Match 객체 이터레이터 순회하기

모든 일치 항목의 텍스트뿐만 아니라 매칭 위치(인덱스)나 캡처 정보가 필요한 대용량 텍스트 처리 시 사용합니다.

```python
import re

text = "Item A: $12, Item B: $45, Item C: $99"
for match in re.finditer(r"\$(\d+)", text):
    print(f"가격: {match.group(1)}, 위치: {match.span()}")
```

```text
가격: 12, 위치: (8, 11)
가격: 45, 위치: (21, 24)
가격: 99, 위치: (34, 37)
```

- `re.finditer()`는 결과를 한번에 메모리에 올리지 않고 `Match` 객체 이터레이터(Iterator)를 반환하므로 메모리 효율적입니다.
- 각 루프 단계에서 `Match` 객체의 모든 메타데이터 메서드를 사용할 수 있습니다.

## re.sub()로 패턴 일치 문자열 치환하기

민감 정보(주민번호, 이메일)를 마스킹하거나 특정 패턴의 문자열을 다른 텍스트로 일괄 변경할 때 사용합니다.

```python
import re

user_data = "연락처: 010-9876-5432, 비상연락처: 010-1111-2222"
masked_numbers = re.sub(r"(\d{3}-\d{4}-)\d{4}", r"\1****", user_data)

print("치환 결과:", masked_numbers)
```

```text
치환 결과: 연락처: 010-9876-****, 비상연락처: 010-1111-****
```

- 첫 번째 인자로 정규식 패턴, 두 번째 인자로 치환할 문자열, 세 번째 인자로 대상 텍스트를 받습니다.
- 치환 문자열에서 `\1`, `\2` 백레퍼런스를 사용해 패턴에서 캡처한 그룹 내용을 그대로 유지하면서 치환할 수 있습니다.

## re.split()로 패턴 기준 문자열 분할하기

단순 단일 문자가 아닌 쉼표, 공백, 세미콜론 등 여러 종류의 구분 기호가 섞여 있는 텍스트를 분할할 때 사용합니다.

```python
import re

raw_csv = "apple, banana; cherry  orange\tgrape"
tokens = re.split(r"[,;\s]+", raw_csv)

print("분할된 토큰 목록:", tokens)
```

```text
분할된 토큰 목록: ['apple', 'banana', 'cherry', 'orange', 'grape']
```

- `re.split(pattern, string)`은 정규표현식 패턴과 매칭되는 모든 구간을 기준으로 문자열을 잘라 리스트로 반환합니다.
- 패턴에 캡처 그룹 `()`을 포함시키면 구분 기호 문자 자체도 결과 리스트에 포함됩니다.
