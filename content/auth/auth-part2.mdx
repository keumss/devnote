title: "Part 2. 중급: PyJWT로 JWT Access Token 생성 및 검증하기"

웹 API는 클라이언트의 상태를 서버에 저장하지 않는 무상태(Stateless) 아키텍처를 주로 사용합니다. 이 노트에서는 `PyJWT` 라이브러리를 사용해 사용자 인증 정보를 안전하게 포함하는 JSON Web Token(JWT)을 발급하고 디코딩하여 검증하는 중급 패턴을 다룹니다.

## JWT 구조와 PyJWT 라이브러리 설치하기

서버와 클라이언트 간에 클레임(Claim) 정보를 점(.)으로 구분된 헤더(Header)·페이로드(Payload)·서명(Signature)의 3가지 JSON 인코딩 문자열로 전달할 때 JWT와 `PyJWT` 패키지를 사용합니다.

```bash
pip install pyjwt
```

`PyJWT`는 Python 3.12 표준 환경에서 HMAC-SHA256(HS256)을 포함한 다양한 암호화 서명 알고리즘을 지원합니다.

## jwt.encode()로 sub와 exp를 담은 Access Token 발급하기

로그인 성공 후 사용자의 식별자(`sub`)와 토큰 만료 시간(`exp`)을 암호화 서명하여 Access Token 문자열로 발급할 때 `jwt.encode()`를 사용합니다.

```python
from datetime import datetime, timezone, timedelta
import jwt

SECRET_KEY = "my-super-secret-key-for-jwt-token"
ALGORITHM = "HS256"


def create_access_token(user_id: int, expires_delta: timedelta = timedelta(minutes=15)) -> str:
    now = datetime.now(timezone.utc)
    payload = {
        "sub": str(user_id),
        "iat": now,
        "exp": now + expires_delta,
    }
    return jwt.encode(payload, SECRET_KEY, algorithm=ALGORITHM)


token = create_access_token(user_id=42)
print(token)
```

```text
eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiI0MiIsImlhdCI6MTczNzc4MjQwMCwiZXhwIjoxNzM3NzgzMzAwfQ.signature_hash_bytes
```

`exp` 클레임에는 UTC 기준 Epoch 시간(Timestamp) 형태의 datetime 객체를 지정하며, 서버만 아는 `SECRET_KEY`로 서명해야 클라이언트가 페이로드를 위조할 수 없습니다.

## jwt.decode()로 토큰 서명 검증 및 클레임 추출하기

클라이언트가 HTTP 헤더로 전달한 토큰의 서명을 검증하고 내부 사용자 ID(`sub`)를 추출할 때 `jwt.decode()`를 사용합니다.

```python
from datetime import datetime, timezone, timedelta
import jwt

SECRET_KEY = "my-super-secret-key-for-jwt-token"
ALGORITHM = "HS256"

# 토큰 생성
now = datetime.now(timezone.utc)
token = jwt.encode({"sub": "42", "exp": now + timedelta(minutes=15)}, SECRET_KEY, algorithm=ALGORITHM)

# 토큰 디코딩 및 검증
payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
user_id: str = payload.get("sub")

print(f"Decoded User ID: {user_id}")
```

```text
Decoded User ID: 42
```

`jwt.decode()`는 전달받은 토큰의 서명이 `SECRET_KEY`와 일치하는지 확인하고, 기본적으로 `exp` 만료 시간을 자동으로 검사합니다.

## ExpiredSignatureError로 만료된 토큰 예외 처리하기

토큰의 유효 기간(`exp`)이 지난 요청을 수신했을 때 `jwt.ExpiredSignatureError` 예외를 포착하여 만료 응답을 반환합니다.

```python
from datetime import datetime, timezone, timedelta
import jwt

SECRET_KEY = "my-super-secret-key-for-jwt-token"
ALGORITHM = "HS256"

# 이미 만료된 과거 시간으로 토큰 생성
past_time = datetime.now(timezone.utc) - timedelta(minutes=10)
expired_token = jwt.encode({"sub": "42", "exp": past_time}, SECRET_KEY, algorithm=ALGORITHM)

try:
    jwt.decode(expired_token, SECRET_KEY, algorithms=[ALGORITHM])
except jwt.ExpiredSignatureError:
    print("Caught ExpiredSignatureError: 토큰이 만료되었습니다.")
```

```text
Caught ExpiredSignatureError: 토큰이 만료되었습니다.
```

만료된 토큰을 사용할 경우 서명이 올바르더라도 `ExpiredSignatureError`가 발생하므로 클라이언트에게 재로그인이나 토큰 갱신을 요청해야 합니다.

## InvalidTokenError로 변조되거나 잘못된 토큰 거부하기

토큰의 서명이 훼손되었거나 `SECRET_KEY`가 맞지 않는 조작된 토큰을 검출할 때 `jwt.InvalidTokenError` 예외를 처리합니다.

```python
import jwt

SECRET_KEY = "my-super-secret-key-for-jwt-token"
ALGORITHM = "HS256"

invalid_token = "eyJhbGciOiJIUzI1NiJ9.invalid_payload.invalid_signature"

try:
    jwt.decode(invalid_token, SECRET_KEY, algorithms=[ALGORITHM])
except jwt.InvalidTokenError as e:
    print(f"Invalid Token: {type(e).__name__}")
```

```text
Invalid Token: DecodeError
```

`InvalidTokenError`는 `DecodeError`, `InvalidSignatureError` 등 모든 잘못된 토큰 관련 예외의 상위 클래스이므로, 인증 실패 응답을 통합 처리할 때 유용합니다.

## Refresh Token으로 Access Token 재발급 흐름 이해하기

유효 기간이 짧은 Access Token(예: 15분)과 유효 기간이 긴 Refresh Token(예: 7일)을 분리하여 보안과 사용자 경험을 모두 확보할 때 Refresh Token 발급 함수를 작성합니다.

```python
from datetime import datetime, timezone, timedelta
import jwt

SECRET_KEY = "my-super-secret-key-for-jwt-token"
ALGORITHM = "HS256"


def create_token_pair(user_id: int) -> dict[str, str]:
    now = datetime.now(timezone.utc)
    access_payload = {"sub": str(user_id), "type": "access", "exp": now + timedelta(minutes=15)}
    refresh_payload = {"sub": str(user_id), "type": "refresh", "exp": now + timedelta(days=7)}
    
    return {
        "access_token": jwt.encode(access_payload, SECRET_KEY, algorithm=ALGORITHM),
        "refresh_token": jwt.encode(refresh_payload, SECRET_KEY, algorithm=ALGORITHM),
    }


tokens = create_token_pair(user_id=42)
print("Keys in token pair:", list(tokens.keys()))
```

```text
Keys in token pair: ['access_token', 'refresh_token']
```

`type` 클레임을 추가하여 Refresh Token으로 API 요청을 시도하거나 Access Token으로 토큰 재발급을 시도하는 부적절한 호출을 차단할 수 있습니다.
