title: "Part 3. 고급: FastAPI Security와 OAuth2PasswordBearer 연동하기"
---

FastAPI는 의존성 주입(Dependency Injection)과 OpenAPI 자동 문서화를 위한 강력한 보안 시스템을 기본 제공합니다. 이 노트에서는 `fastapi.security` 모듈의 `OAuth2PasswordBearer`를 사용해 HTTP 요청 헤더에서 JWT를 검증하고 역할 기반 접근 제어(RBAC)를 구현하는 고급 패턴을 다룹니다.

## OAuth2PasswordBearer로 Swagger UI에 인증 스키마 등록하기

FastAPI 대화형 API 문서(`/docs`)에 OAuth2 로그인 버튼과 Bearer 인증 스키마를 등록할 때 `OAuth2PasswordBearer`를 인스턴스화합니다.

```python
from fastapi import FastAPI
from fastapi.security import OAuth2PasswordBearer

app = FastAPI()
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")
```

`tokenUrl="token"`은 OpenAPI 규격 상 클라이언트가 로그인 요청(POST)을 보낼 상대 경로를 의미하며, `/docs` 화면 상단의 **Authorize** 버튼에 연동됩니다.

## Depends()로 요청 Authorization 헤더에서 Bearer 토큰 추출하기

API 엔드포인트 함수 인자에 `token: str = Depends(oauth2_scheme)`를 선언하여 클라이언트 요청의 `Authorization: Bearer <token>` 헤더 값을 자동으로 가져옵니다.

```python
from fastapi import Depends, FastAPI
from fastapi.security import OAuth2PasswordBearer

app = FastAPI()
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")


@app.get("/items")
def read_items(token: str = Depends(oauth2_scheme)):
    return {"received_token": token[:10] + "..."}
```

클라이언트가 `Authorization` 헤더를 누락했거나 `Bearer` 형식이 아니면 FastAPI가 엔드포인트 함수 실행 전 자동으로 `401 Unauthorized` 응답을 돌려줍니다.

## get_current_user 의존성 함수로 토큰 검증 및 유저 조회 연결하기

추출한 토큰을 디코딩하여 현재 요청을 보낸 유저 정보를 조회하는 재사용 가능한 의존성 함수 `get_current_user`를 구현합니다.

```python
from datetime import datetime, timezone, timedelta
from fastapi import Depends, FastAPI, HTTPException, status
from fastapi.security import OAuth2PasswordBearer
import jwt

SECRET_KEY = "my-super-secret-key"
ALGORITHM = "HS256"

app = FastAPI()
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")


def get_current_user(token: str = Depends(oauth2_scheme)) -> dict[str, str]:
    credentials_exception = HTTPException(
        status_code=status.HTTP_401_UNAUTHORIZED,
        detail="자격 증명을 검증할 수 없습니다.",
        headers={"WWW-Authenticate": "Bearer"},
    )
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        username: str | None = payload.get("sub")
        if username is None:
            raise credentials_exception
    except jwt.InvalidTokenError:
        raise credentials_exception

    # 실제 앱에서는 DB에서 username으로 유저 객체를 조회합니다.
    return {"username": username, "role": "author"}
```

`Depends(get_current_user)`를 개별 API 엔드포인트 파라미터로 지정하면 인증된 유저 객체를 손쉽게 주입받아 활용할 수 있습니다.

## HTTPException(status_code=401)로 WWW-Authenticate 헤더 예외 반환하기

인증에 실패했을 때 OAuth2 규격(RFC 6750)에 맞추어 `401 Unauthorized` 상태 코드와 함께 `WWW-Authenticate: Bearer` 헤더를 내려줍니다.

```python
from fastapi import HTTPException, status

credentials_exception = HTTPException(
    status_code=status.HTTP_401_UNAUTHORIZED,
    detail="토큰이 만료되었거나 유효하지 않습니다.",
    headers={"WWW-Authenticate": "Bearer"},
)
```

`WWW-Authenticate` 헤더는 프론트엔드 브라우저 및 API 클라이언트에 보호된 자원에 접근하기 위해 어떤 인증 방식(Bearer)을 사용해야 하는지 명확히 알려줍니다.

## Role Enum으로 API 접근 권한(RBAC) 검사 의존성 만들기

일반 사용자, 포스트 작성자(Author), 관리자(Admin) 등 유저의 역할(Role)에 따라 특정 API 접근을 제한하는 권한 검사 의존성을 작성합니다.

```python
from enum import Enum
from fastapi import Depends, HTTPException, status

class UserRole(str, Enum):
    ADMIN = "admin"
    AUTHOR = "author"
    USER = "user"


def require_role(required_role: UserRole):
    def role_checker(current_user: dict = Depends(get_current_user)):
        if current_user.get("role") != required_role and current_user.get("role") != UserRole.ADMIN:
            raise HTTPException(
                status_code=status.HTTP_403_FORBIDDEN,
                detail="해당 작업에 대한 권한이 없습니다.",
            )
        return current_user

    return role_checker
```

`@app.delete("/posts/{id}", dependencies=[Depends(require_role(UserRole.ADMIN))])`과 같이 선언하면 관리자 권한을 가진 유저만 엔드포인트를 호출할 수 있습니다.

## HTTPBearer와 OAuth2PasswordBearer 차이점 및 선택 기준 비교하기

FastAPI가 제공하는 `HTTPBearer`와 `OAuth2PasswordBearer` 보안 클래스의 용도 차이 및 적용 상황을 비교합니다.

```python
from fastapi.security import HTTPBearer, OAuth2PasswordBearer

# 1. OAuth2 패스워드 플로우 기반 (Swagger /docs 로그인 Form 제공)
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")

# 2. 단순 HTTP Bearer 헤더 추출 전용 (외부 SSO / Auth0 / Firebase 토큰 수신용)
http_bearer_scheme = HTTPBearer()
```

- `OAuth2PasswordBearer`: 자체 비밀번호 로그인 엔드포인트를 제공하고 OpenAPI 대화형 문서에서 직접 로그인 테스트를 수행할 때 적합합니다.
- `HTTPBearer`: 외부 인증 서버(OAuth2 Provider)가 발급한 JWT를 전달받아 단순히 `Authorization: Bearer <token>` 헤더만 추출할 때 유용합니다.
